Everything you need to ship pixel-perfect UI

A full inspection toolkit that runs entirely in your browser — no setup, no accounts, no data leaving your machine.

Inspect

Hover any element for its selector, box model, computed CSS, and ancestry. Screenshot it to PNG or copy its styles as a CSS rule.

Measure distances

Select one element, hover another — exact pixel distances, live, right inside Inspect. Rulers and a crosshair ride along.

Nudge

Drag or arrow-key elements around the live page and compare against a ghost of the original — then export the change list for your developer or AI agent, with before/after screenshots.

Layout grid & rulers

Overlay a configurable column/gutter/margin grid, plus pixel rulers along the viewport edges.

Color picker

A live magnifier samples the exact pixel under your cursor. Build a palette with hex/RGB/HSL, CSS-variable matches, and a WCAG contrast checker.

Xray & find

Outline the page's full element structure at a glance, or find elements by text or CSS selector and cycle through matches.

Responsive mode

Preview any URL with true device emulation — viewport, touch, and user agent — in a real tab, so login and SSO flows keep working.

Figma compare PRO

Anchor a Figma frame to your live DOM and get a per-element diff heatmap with severity grading and design-token hints.

Breakpoint batch compare PRO

Compare one Figma frame per breakpoint: Loupe reflows the page to each width and tabulates the differences.

Accessibility audit PRO

Page-wide scan for WCAG contrast failures, missing alt text, small tap targets, unlabeled fields, and heading-order issues.

AI fix suggestions & QA reports PRO

Optional AI-written fix suggestions using your own Anthropic API key, and one-click export of a standalone QA report.
